No scanner, network access, package installation, application repository write or live model call is enabled by installing AEO-4. Missing configured validators block governed readiness. Policies require explicit authenticated human activation. Legacy milestones retain their earlier workflow until adoption; production use requires adopting policies for every delivery milestone.
